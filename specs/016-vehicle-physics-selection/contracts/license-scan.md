# Contract: License scan

The automated scan of every component a candidate adds beyond the shared core's own builds (FR-031).
Our own code in `src/MmoEngine.SimCore.Vehicles.Selection/License/`, in three stages: collectors, a
boundary step and a pure classifier (research R18). External tools are not the gate.

## Inventory

A collector's output, and the classifier's input. Canonical JSON: UTF-8, LF, sorted keys, components
sorted by (ecosystem, name, version, origin), no timestamps, no absolute paths (paths are relative to a
named root: `<repo>`, `<nuget>`, `<cargo>`, `<sysroot>`, `<jolt>`, `<emsdk>`, `<os>`).

```json
{
  "formatVersion": 1,
  "candidate": "jolt",
  "target": "browser",
  "components": [
    { "ecosystem": "source", "name": "Jolt/Physics/PhysicsSystem.cpp", "version": "v5.7.0", "expression": "MIT", "basis": "spdx-header", "origin": "<jolt>/Jolt/Physics/PhysicsSystem.cpp" },
    { "ecosystem": "emscripten", "name": "libemmalloc.a(emmalloc.o)", "version": "3.1.56", "expression": "MIT OR NCSA", "basis": "notice", "origin": "<emsdk>/system/lib/emmalloc.c" }
  ]
}
```

| Field | Rule |
| --- | --- |
| `ecosystem` | `nuget`, `runtime-pack`, `cargo`, `rust-sysroot`, `source`, `emscripten`, `os-toolchain` |
| `expression` | the SPDX expression as declared, or `null` when none is declared |
| `basis` | `nuspec-expression`, `nuspec-override`, `cargo-license`, `spdx-header`, `notice`, `owner-default`, `package-copyright` |
| `origin` | where the component was found, relative to its root |

## Collectors

| Ecosystem | Server target | Browser target |
| --- | --- | --- |
| `nuget` | the publish's `<app>.deps.json` libraries of `"type": "package"`, each license from the package's `.nuspec` in the global packages folder | `project.assets.json` `targets["net10.0/browser-wasm"]` packages with runtime assets whose assembly appears in the published boot manifest |
| `runtime-pack` | assemblies from `Microsoft.NETCore.App.Runtime.*` (boundary) | assemblies from `Microsoft.NETCore.App.Runtime.Mono.browser-wasm` (boundary) |
| `cargo` | `cargo metadata --format-version 1 --locked --offline --filter-platform x86_64-unknown-linux-gnu` after `cargo fetch --locked`: normal edges from the shim, proc-macro crates and their exclusive subgraphs dropped | the same with `--filter-platform wasm32-unknown-unknown` |
| `rust-sysroot` | the sysroot rlibs in the link trace, licenses from `rustlib/src/rust/library/**/Cargo.toml` (only when a Rust artifact is built) | the same |
| `source` | every file under the Jolt root in the build's compiler depfiles (`*.o.d`); each must carry `SPDX-License-Identifier: MIT` | the same, from the Emscripten build |
| `emscripten` | | every `lib*.a(member.o)` of `-Wl,--trace`, mapped through `simcore/vehicles/license/emscripten-3.1.56.json` to its source, classified by the source's notice or its owner's default; headers from the depfiles; the JavaScript glue |
| `os-toolchain` | every `NEEDED` entry of the shim (`readelf -d`), and every static input of its link map (`crti.o`, `crtn.o`, `crtbeginS.o`, `crtendS.o`, `libgcc.a`, `libc_nonshared.a`) and libstdc++ header in the depfiles, mapped by `dpkg -S` to its runner-image package | |

A `.nuspec` with `<license type="file">` or only a `<licenseUrl>` is `NoLicense` unless
`simcore/vehicles/license/overrides.json` names the package, its version and its expression with the
evidence. An Emscripten archive member missing from the table, or a table whose version differs from the
pinned Emscripten, fails closed (`NoLicense`).

The Emscripten table is generated by `tools/vehicles/license/gen_emscripten_table.py` from the pinned
packs' `tools/system_libs.py` and committed; the scan never regenerates it.

## Boundary

`simcore/vehicles/license/boundary.json` lists what the core-only builds already load and ship, by
source package, each with its expression and evidence:

| Package | Why it is in the boundary |
| --- | --- |
| `glibc` (`libc6`, `libc6-dev`) | the core-only server process maps `libc.so.6`, `libm.so.6` and `ld-linux-x86-64.so.2`; the system linker adds `crti.o`, `crtn.o`, `libc_nonshared.a` |
| `gcc-N` (`libgcc-s1`, `libgcc-N-dev`) | the process maps `libgcc_s.so.1`; the linker adds `crtbeginS.o`, `crtendS.o`, `libgcc.a` |
| `gcc-N` (`libstdc++6`, `libstdc++-N-dev`) | the process maps `libstdc++.so.6`; header-instantiated libstdc++ code in a shim is that component |
| the .NET runtime pack | the same for every candidate and for the core alone |
| the .NET WebAssembly runtime (`dotnet.native.wasm`, its zlib, Brotli, ICU and dlmalloc) | shipped by every core-only browser build |

`BoundaryTests.TheCoreOnlyServerMapsTheBoundaryLibraries` runs the core-only server build (`simcore
streams verify` on one 015 stream) and reads its `/proc/self/maps`; every shared library a candidate's
shim NEEDs must be in that set, and one outside it is an added component. Boundary components appear in
the report under `boundary` and never block (research R18). This component-level reading decides
nothing about how Principle VII treats platform libraries (patch-notes follow-up 1).

## Classifier

`LicenseClassifier.Classify(inventory, boundary)` is pure. For each component not in the boundary:

1. Parse the expression: SPDX syntax with precedence WITH > AND > OR, parentheses, and Cargo's legacy
   `A/B` read as `A OR B`.
2. Evaluate: `MIT` and `Apache-2.0` pass; `Apache-2.0 WITH LLVM-exception` passes as Apache-2.0; any other
   `WITH`, any other identifier, `+`, and `LicenseRef-*` fail; `OR` passes when one side passes; `AND`
   passes when both pass.
3. A null or empty expression is `NoLicense`; one that does not parse is `UnparseableExpression`; one that
   evaluates to fail is `LicenseNotAllowed`.

| Expression | Verdict |
| --- | --- |
| `MIT AND Apache-2.0 WITH LLVM-exception AND (MIT OR Apache-2.0)` | pass |
| `MIT/Apache-2.0` | pass |
| `Zlib OR Apache-2.0 OR MIT` | pass |
| `Unlicense OR MIT` | pass |
| `MIT OR NCSA` | pass |
| `MIT OR Apache-2.0 AND BSD-3-Clause` | pass (`MIT OR (…)`) |
| `(MIT OR Apache-2.0) AND Unicode-3.0` | `LicenseNotAllowed` |
| `Zlib` | `LicenseNotAllowed` |
| `CC0-1.0` | `LicenseNotAllowed` |
| `SunPro` | `LicenseNotAllowed` |
| `GPL-3.0-only` | `LicenseNotAllowed` |
| `GPL-3.0-or-later WITH GCC-exception-3.1` | `LicenseNotAllowed` (outside the boundary) |
| `MIT AND (` | `UnparseableExpression` |
| empty or null | `NoLicense` |

## Output

The report's `license` member per candidate and target:

```json
{
  "verdict": "Blocked",
  "blocked": [ { "component": "foldhash", "version": "0.2.0", "expression": "Zlib", "reason": "LicenseNotAllowed" } ],
  "boundary": [ { "component": "libstdc++6", "expression": "GPL-3.0-or-later WITH GCC-exception-3.1", "evidence": "mapped by the core-only server process" } ],
  "componentCount": 49
}
```

A `Blocked` verdict on any target makes the candidate LicenseBlocked (`LicenseNotAllowed`) in every
mode, and for Rapier fails criterion (c). Every blocked component goes to the decision record's
`amendmentCandidates`.

## Build settings the scan relies on

- Emscripten builds link with `-sMALLOC=emmalloc` and `-Wl,--trace`; a test asserts the trace has
  `libemmalloc.a(emmalloc.o)` and no `libdlmalloc.a` member.
- The Jolt server shim links libstdc++ dynamically (no `-static-libstdc++`).
- A Rust browser module (the Rapier follow-up) uses raw exports, never wasm-bindgen.

## Tests

All in process except the collector runs; none needs the network.

- `SpdxTests`: a Theory over the table above, precedence and parentheses.
- `ClassifierGoldenTests`: committed `simcore/vehicles/fixtures/license/<case>.inventory.json` in,
  `<case>.expected.json` compared byte for byte: all allowed (Pass); a transitive dependency licensed
  `GPL-3.0-only` (Blocked, naming the component and the expression; US2 scenario 10); `dlmalloc` as
  `CC0-1.0`; a Sun-notice musl member as `SunPro`; foldhash as `Zlib`; an unmapped member (`NoLicense`);
  an OS-toolchain component (boundary, not blocking); a NuGet license by file or bare URL (`NoLicense`).
- `CollectorTests`: a committed path-only Cargo workspace with a `GPL-3.0-only` path dependency (run with
  an empty `CARGO_HOME`, offline); a committed `project.assets.json`, `deps.json` and `.nuspec` tree;
  committed `--trace` and depfile excerpts with a small Emscripten table.
- `BoundaryTests` above, and the emmalloc trace assertion in the native tests.
- The US2 scenario 10 orchestration test: the fixture license input through the selection orchestration
  makes that candidate LicenseBlocked in every mode, evaluates the others and exits 0.
